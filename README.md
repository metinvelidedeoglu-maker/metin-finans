# Metin Finans

Borç, kredi, kredi kartı, ek hesap, çek ve sabit gider takip uygulaması.

- Google ile giriş
- Firebase Firestore ile otomatik senkronizasyon
- Mobil ve masaüstü uyumlu
- Çevrimdışı kullanım desteği
- Ödeme ekleme, düzenleme, silme ve ödendi işaretleme
- JSON yedek ve CSV dışa aktarma

Finansal veriler GitHub deposunda tutulmaz. Veriler Firebase Firestore üzerinde, kullanıcı hesabına bağlı olarak saklanır.
